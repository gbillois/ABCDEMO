# Sources des fichiers de `dragonflyer/assets/`

Tous les modèles sont faits par les scripts Blender de `blender/dragonflyer/`, sauf les mouvements de `animations.glb` :

| Fichier | Origine | Licence |
|---|---|---|
| `animations.glb` | Mouvements (repos, marche, trot, course, saut, réception, coup d'épée, parler, prendre) de la « Universal Animation Library » de Quaternius, version Standard (https://opengameart.org/content/universal-animation-library), transférés sur le squelette du héros par `blender/dragonflyer/animations.py`. Aucun personnage ni maillage de la bibliothèque n'est utilisé. | CC0 1.0 (domaine public), usage commercial autorisé |
| tous les autres `.glb` | faits par les scripts Blender du dépôt | — |
